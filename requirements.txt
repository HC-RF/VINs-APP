# =============================================================================
# One dependency set serving both frontends:
#   streamlit run streamlit_app.py     -> Streamlit Community Cloud
#   uvicorn app.main:app               -> FastAPI + the static SPA
#
# Streamlit Cloud installs from this file at the repository root.
#
# Version note: Streamlit 1.62 requires starlette 1.x, which FastAPI only
# supports from 0.116 onward. Pinning FastAPI below that produces a
# `Router.__init__() got an unexpected keyword argument 'on_startup'` error at
# import time. The combination pinned here is verified: 316 tests pass and both
# frontends run against it.
# =============================================================================

# --- Streamlit frontend -----------------------------------------------------
